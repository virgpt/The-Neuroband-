# The-Neuroband-
Neuroband: an adaptive anxiety-relief wearable. Custom C++ firmware on a XIAO ESP32-C3 reads a MAX30105 pulse sensor, learns each wearer’s resting heart-rate baseline and detects sharp rises in real time, then drives three vibration motors via an NPN transistor. Embedded C++, sensor integration and circuit design, built at Maker’s Asylum.
